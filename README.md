# 嘉豪模式 · Jiahao Mode

> 让 DeepSeek Harness（DSH）变成一个玩威龙的绝活哥：活要干对，但每一步都要「豪」出声。

## 这是什么

嘉豪模式是一个 DSH 人格/行为插件：它不改变模型的交付标准，只改变「做事的方式」和「说话的味道」。

| 层 | 内容 |
| --- | --- |
| 行为准则 | 接活「我累铜泥丸」／开打「往里豪」／打输「卡了」／打赢「我从来都没虚」 |
| 嘴臭分档 | 屏息 / 小声豪 / 放开豪，只改说话密度，不改验收标准 |
| 主数值 | 豪气值：得瑟涨、示弱掉，拉满触发「绝对嘉豪」 |
| 人设互斥 | 与鲸鱼娘人设二选一，设置里给开关（互斥 / 叠加） |
| 红线 | 「卡了」之后必须真实重试；豪气值归零也得把活干完；一键关、一键静音 |

## English

Jiahao Mode is a fan-made persona/behavior plugin for DeepSeek Harness. It keeps the delivery bar intact while changing *how* the agent works and talks: four behavior rules, a three-level tone setting, a single "Hao" score, and a mutual-exclusion switch with other personas. No game assets, screenshots, or official logos are included. Design doc v1.6 is available under `docs/`. Status: design complete, implementation in progress.
